# ExecPlan M2: fondamenta e prima slice scientifica

Stato: **IN PROGRESS**. Prerequisito M1 soddisfatto: `docs/decisions/ADR-M1-stack.md` adottato il 28 ottobre 2026.

## Ambito

Unità M2.a–g del piano §21.4 (righe 2659-2675). Produce la libreria core headless C++20 e la prima slice di calibrazione su FITS. Fuori: RAW (M3.a), otto combinazioni complete (M3.c), GUI (M4).

## Prerequisiti

- ADR-01/02/04/07.a e strategia hash decisi in `ADR-M1-stack.md`.
- Dipendenze di sistema già presenti (nessuna installazione): CFITSIO 4.6.3, SQLite 3.46.1, OpenSSL 3.5.5, FFTW 3.3.10, GoogleTest 1.17 (copia in `third_party/googletest`), Eigen 3.4. Licenze compatibili con GPL-3.0-or-later; inventario in M2.f.

## Struttura del codice

```
CMakeLists.txt           radice, C++20, -Wall -Wextra -Wpedantic -Werror, -fno-fast-math -ffp-contract=off
src/core/                libastrocore: image, fits, hash, dag, store, sched, calib
tests/unit/              GoogleTest, un file per modulo
tests/fixtures/          generatori deterministici; nessun binario versionato
docs/contracts/          contratti minimi M2.g
build/                   ignorata da git
```

Preset CMake `dev` (Debug, ASan+UBSan) e `release` (RelWithDebInfo). Comando unico di verifica: `cmake --preset dev && cmake --build --preset dev && ctest --preset dev`.

**Gate M2** (riga 2675): slice FITS con L−D, Q, maschere, metadati, incertezza e report; DAG durevole, recovery, cancel e worker. Serve anche un dato astronomico reale: un FITS pubblico con licenza verificata (light, dark, flat e dark-flat, oppure un dark all'esposizione del flat dichiarato nella ricetta con ruolo `dark_flat`), scelto e registrato in M2.f.

## Contratto scientifico M2.e

Modello §8.3–8.5 e contratto C-01 §10.2 nella forma minima. Unità ADU. Ipotesi: dark matched per esposizione, gain, temperatura e offset dichiarati nei metadati; incompatibilità → stop prima dell'esecuzione, non ricetta alternativa. Normalizzazione N dichiarata (mediana globale o per canale CFA). Casi degeneri: Q ≤ 0, non finito o sotto soglia dichiarata → pixel invalido nella maschera.
